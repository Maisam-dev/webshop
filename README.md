# Webshop - Mini E-Commerce App

A responsive, lightweight single-page e-commerce web application built with **Vue.js**. This project demonstrates dynamic product listing, category filtering, and shopping cart operations.

---

## Features

- **Product Showcase:** Browse items fetched dynamically from API.
- **Category Filtering:** Filter products dynamically by selected categories.
- **Shopping Cart System:** Add, remove, and view total cart items in real time.
- **Responsive UI:** Clean interface optimized for desktop and mobile views.

---

## Tech Stack

- **Framework:** Vue.js
- **State Management / Services:** Pinia / Custom JS Store Modules
- **Build Tool:** Vue CLI / Vite
- **Styling:** CSS3 / Modern Layouts

---

## Getting Started Locally

### Prerequisites

Make sure you have Node.js installed on your system.

### Installation & Setup

. **Clone the repository:**

```bash
git clone https://github.com/Maisam-dev/webshop.git

--Navigate into the project directory:
cd webshop


--Install dependencies:
npm install


--Run the development server:
npm run serve

--Open your browser at http://localhost:8080/.
```
